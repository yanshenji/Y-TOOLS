# 工具宏（Excel-DNA 版）功能清单

> 版本 0.1.0 ｜ 2026-11-27 ｜ 适用于 Excel 与 WPS（32 位）
> 功能区选项卡「工具宏」共 9 个分组。每个命令在「加载项」菜单下也有一份（菜单名：工具宏·文件 / 工具宏·筛选 …），功能区显示不出来时可以从那里用。

## 一、功能区命令

## 二、工作表函数（公式中使用，函数名与原 VBA 相同）

| 函数 | 作用 |
|---|---|
| `=cmpStd(标准, 数值)` | 判断数值是否符合标准表达式，如 ≥10、≤0.5、5~10、5-10 |
| `=cmpStd2(标准区域, 数值区域, [返回类型])` | 逐格比对，全部符合才合格。返回类型：1=TRUE/FALSE 2=合格/不合格 3=符合/不符合 4=1/2 |
| `=Cpk_MR(数据, LSL, USL)` | 单值移动极差法 Cpk |
| `=Ppk_Calc(数据, LSL, USL)` | 整体标准差 Ppk |
| `=Cpk_Rank(Cpk值)` | 等级：D级-严重不足 / C级-能力不足 / B级-临界尚可 / A级-能力充足 / AA级-能力富余 |
| `=MK(数据, 类型)` | Mann-Kendall 趋势检验。类型：1=S 2=Z 3=P值 4=Sen斜率 5=样本数 |
| `=GrubbsOutliers(数据, [α])` | 迭代 Grubbs 检验，返回检出的异常值（一列） |
| `=GrubbsG(值, 数据)` | 单个点的 G 值 |
| `=GrubbsCrit(n, [α])` | Grubbs 双侧临界值 |
| `=保留两位有效数字_四舍六入五成双(数值)` | 按 GB/T 8170 修约 |
| `=保留两位有效数字_四舍五入(数值)` | 四舍五入到两位有效数字 |
| `=工具宏版本()` | 显示加载项版本，用来确认 .xll 已加载 |
